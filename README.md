# Jaman Community Broadcasting Association

Open index.html to preview the site on your computer. All five pages use relative links and work from a GitHub Pages project subdirectory.

## Host on GitHub Pages

1. Extract the ZIP.
2. Copy its contents into the root of your GitHub repository, including the hidden .nojekyll file.
3. In the repository, go to Settings → Pages. Under Build and deployment, choose Deploy from a branch. Select your publishing branch and / (root), then save.

The site uses plain HTML and CSS and requires no build command or server. The studio image is an illustration. All station navigation opens in a new tab.

The muted logo animation is used as the visual background in each page’s top section. It loops automatically on supported browsers. Devices that request reduced motion see a still logo.

The footer lists TikTok, Facebook, Instagram, and YouTube. Add the station’s official profile URLs once confirmed.
